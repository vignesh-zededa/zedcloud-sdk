# Zedcloud MCP Server

Exposes focused ZEDEDA Zedcloud operations as [Model Context Protocol](https://modelcontextprotocol.io/) tools.

## Run

```bash
export ZEDCLOUD_BASE_URL=https://zedcontrol.zededa.net
export ZEDCLOUD_TOKEN=…
uv run zedcloud-mcp
```
